# Tech Layoffs: Data Cleaning

Cleaning a dataset of 489 tech layoff events (2022 to 2023) using Python and pandas.

## What I did
- Audited the raw data and fixed column names and text
- Converted `Unclear` to missing values and fixed data types
- Standardized city and industry spellings
- Added features: `main_industry`, `month`, `quarter`, `layoff_size`
- Validated the result with before/after audits and checks

## Files
- `Tech_layoffs_Hamza.ipynb`: the cleaning notebook
- `tech_layoffs.csv`: original data
- `layoffs_clean.csv`: cleaned data

Data source: Kaggle
